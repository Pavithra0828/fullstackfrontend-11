# TechVibe Expense Tracker - React Frontend

Converted from the supplied HTML/CSS/JavaScript project into a React + Vite frontend.

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

### Included
- Expense Input page
- Dashboard page
- React Router navigation
- Monthly expense tracking
- Add/Edit/Delete daily extra expenses
- LocalStorage persistence
- Summary cards and dashboard charts
- Responsive UI
- Frontend only — no backend/database/API included
